### 🌟 Projets Phares

#### 🎬 **Eveil Kids** - Plateforme de Streaming Éducative
Plateforme interactive dédiée aux enfants avec contenus éducatifs et divertissants
- **Tech** : Next.js, TypeScript, Zustand, Tailwind CSS
- **Features** : Authentification Google, Paiements sécurisés, Back-office admin

#### 🚐 **Vantour92** - Site Vitrine pour Location de Vans de Luxe
Site moderne pour la réservation de vans de luxe avec intégration WhatsApp
- **Tech** : Next.js, TypeScript, Tailwind CSS, API WhatsApp
- **Features** : Réservation en ligne, Galerie interactive, SEO optimisé

#### 🚔 **E-Contravention** - Digitalisation des Contraventions Routières
Solution complète pour la gestion dématérialisée des infractions routières en Côte d'Ivoire
- **Tech** : Laravel, Flutter, MySQL, API REST
- **Features** : Émission numérique, Signature électronique, Paiements en ligne

#### 💼 **Career Incellotus** - Plateforme de Recrutement Multi-langue
Application web de mise en relation candidats/recruteurs avec fonctionnalités avancées
- **Tech** : Laravel, Vue.js, MySQL, API REST
- **Features** : Multi-langue, Filtres avancés, Gestion des candidatures
